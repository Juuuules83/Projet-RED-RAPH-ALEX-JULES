------------------------------------------------------------------------------------------------------

# Comment lancé le projet ? 
Pour pouvoir exécuter et lancer le programme il faut faire quelques manipulations : 
- ouvrez un terminal dans le dossier dans lequel vous voulez mettre les fichier du jeu
- faites " git clone < lien du projet > (vous retrouverez le lien du projet en cliquant sur "code" en vert en haut de la page) 
- une fois effectuer, faites git init projet-Red (cela permet d'initialiser les dépendances) 
- une fois fais il vous suffit de faire git tidy

- ensuite pour lancer le projet faites : go run ./main.go


  # Principe : 
  Le principe du jeu est de combattre Gopher, la mascotte du langage "golang" avec lequel le projet est codé
